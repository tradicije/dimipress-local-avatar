# Security Policy

## Supported versions

Security fixes are provided for the latest released version of DimiPress Local Avatar.

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Send a private report to [aleksa@linux.com](mailto:aleksa@linux.com). For non-sensitive questions, use [github.com/tradicije](https://github.com/tradicije). Include:

- a clear description of the issue and its impact;
- steps to reproduce it;
- the affected plugin and WordPress versions;
- proof of concept details only when they are necessary to understand the issue.

You will receive an acknowledgement as soon as practical. Valid reports will be investigated privately and a fix will be prepared before public disclosure.
